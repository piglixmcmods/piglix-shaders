## VV Technical Notes

1. **Manifest capabilities:** `"pbr"` ✓ present in base pack `manifest.json` (`"capabilities": ["pbr"]`). Note that `shader_compiler.dart` conditionally removes `"pbr"` when `enablePBR == false`.
2. **`min_engine_version` mismatch:**
   - Base pack `manifest.json`: `[1, 21, 120]` ✓ (matches spec).
   - `shader_compiler.dart` line 1271: hard-codes `[1, 21, 80]` ✗ (regression from base pack; should be `[1, 21, 120]`).
3. **Biome count:** **87** `.client_biome.json` files in `biomes/` (81 overworld, 6 Nether/End skipped by `isOverworldAssetPath()`).
   - In the base pack, `components.minecraft:water_appearance` only contains `surface_color` (not `surface_transparency`), and `water_surface_color` / `water_surface_transparency` do **not** exist at the `minecraft:client_biome` root — `shader_compiler.dart` lines 556–557 write invalid top-level keys alongside `components.minecraft:water_appearance`.
   - Only `swampland.client_biome.json` and `mangrove_swamp.client_biome.json` declare `minecraft:water_identifier` (`"pog:swamp_water"`) in the base pack.
4. **Water preset count & identifiers:** **4** water JSON files in `water/`:
   - `water/water.json` → `pog:water`
   - `water/swamp_water.json` → `pog:swamp_water`
   - `water/water_river.json` → `pbr:water_river`
   - `water/water_two.json` → `pbr:water_swamp` *(mismatch with new `VVShaderConfig` spec which expects `water_two.json` to have identifier `pog:deep_ocean`)*
5. **Fog file count:** **33** `.json` files in `fogs/` (27 overworld processed by `isOverworldAssetPath()`, 6 Nether/End preserved untouched; 4 cold-weather files matched by `isColdWeatherFogPath()`: `ice.json`, `snow.json`, `sorta_intense_cold_fog.json`, `taiga.json`; 19 overworld fogs contain `volumetric.media_coefficients.cloud`).
6. **Particle key bugs (`wavingFoliage` & `foliageWaveSpeed`):** All 5 files in `particles/leaves/` use `"minecraft:emitter_rate_steady"` and `"linear_acceleration"`, whereas `shader_compiler.dart` looks for `"minecraft:particle_emitter_rate_steady"` (missing every file) and writes an invalid `"linear_speed"` property on `"minecraft:particle_motion_dynamic"`.
7. **Unsupported `moon_glare_shape`:** `moonSize` writes `moon_glare_shape` into `atmospherics/*.json`, which does not exist in the base pack or Bedrock `minecraft:atmosphere_settings` schema.
8. **Color grading identifier overwrite:** `_writeColorGrading` overwrites `pale_color_grading.json`'s `description.identifier` (`"pog:pale"`) with `"pog:color_grading"`, colliding with `color_grading/color_grading.json`.
9. **PBR fallback schema key:** `pbr/global.json` in the base pack uses `"minecraft:pog_fallback_settings"` (non-standard/pack-specific key rather than `"minecraft:pbr_fallback_settings"`).
10. **Local lighting & point lights:** Base pack has neither `local_lighting/` nor `point_lights/`; `shader_compiler.dart` generates `local_lighting/local_lighting.json` (`format_version: "1.21.60"`, `minecraft:local_light_settings`) and `point_lights/global.json` (`format_version: "1.21.40"`, `minecraft:point_light_settings`).

## Known UI & Schema Gaps

### 1. Duplicated UI Controls in `lib/new_ui.dart`
Context-sensitive cards in `lib/new_ui.dart` render duplicate controls bound to the same `ShaderBuildConfig` state fields:
- `cloudType` — **×4** (Morning, Evening, Night, and Noon context cards at lines 9719, 9788, 9876, 9946)
- `ambientBounce` — **×2** (lines 10217, 10361)
- `emissiveGlow` — **×2** (lines 10292, 10402)
- `waterTransparency` — **×2** (lines 10458, 10568)
- `windSpeed` — **×2** (lines 10517, 10617)
- `underwaterCaustics` — **×2** (lines 10530, 10582)
- `wetSurfaceGloss` — **×2** (lines 10795, 10870)

### 2. UI Controls Without a Direct VV JSON Field
The following controls in `lib/new_ui.dart` have **no direct native Vibrant Visuals JSON field** (they are either completely non-functional or approximated via unrelated fields):
- **Sun / Moon disc scale** (`sunSize`, `sunSizeMorning`, `sunSizeEvening`, `moonSize`): VV has no sun/moon disc size property; `sunSize*` scales `sun_glare_shape` (glare lobe sharpness), while `moonSize` writes an invalid `moon_glare_shape` key.
- **Cloud shape & colors** (`cloudType`, `cloudTopColor`, `cloudBottomColor`): VV has no cloud geometry/type or top/bottom cloud tint keys; the compiler approximates them via `volumetric.media_coefficients.cloud.scattering` and `.absorption` (absent from 8 of 27 overworld fog files).
- **Bloom & Auto Exposure** (`bloomIntensity`, `autoExposure`): VV exposes no bloom threshold/radius or auto-exposure adaptation setting; approximated via `color_grading.highlights.{gain,contrast}`, `midtones.gain`, and `sun.illuminance`.
- **Waving Foliage** (`wavingFoliage`, `foliageWaveSpeed`): VV has no vertex-wind JSON toggle; `shader_compiler.dart` patches `particles/leaves/*.particle.json` using the wrong component key (`minecraft:particle_emitter_rate_steady` instead of `minecraft:emitter_rate_steady`) and writes an invalid `linear_speed` property.
- **Rain / Puddle / Frost / Wet Gloss** (`rainOvercast`, `puddleColor`, `puddleReflections`, `frostShimmer`, `wetSurfaceGloss`, `coldSkyTint`): VV has no per-weather puddle color, puddle reflection toggle, frost shimmer, or wetness glossiness JSON fields; approximated by blending into `distance.weather.fog_color` or overwriting global `pbr/global.json` roughness/subsurface (`[2]` / `[3]`).

### 3. Schema Discrepancies vs. Official Microsoft Learn VV Docs (`1.21.90`–`1.21.120`)
1. **`local_lighting/local_lighting.json` (`1.21.120`):** Official VV schema maps block IDs directly under `minecraft:local_light_settings` as `{"minecraft:torch": {"light_color": "#...", "light_type": "point_light" | "static_light"}}` — **not** a `description` + `colors` map (which `shader_compiler.dart` emits with `format_version: "1.21.60"` alongside legacy `point_lights/global.json`).
2. **`pbr/global.json`:** Official VV root key is `minecraft:pbr_fallback_settings`, **not** `minecraft:pog_fallback_settings` (present in both the base pack and `shader_compiler.dart`).
3. **Vanilla `biomes/*.client_biome.json` (`1.21.90+`):** Official VV requires explicit `minecraft:atmosphere_identifier`, `minecraft:lighting_identifier`, `minecraft:color_grading_identifier`, `minecraft:water_identifier`, and `minecraft:fog_appearance` components across biomes. In `/tmp/base_shader_audit/biomes/` (87 files), only `minecraft:fog_appearance` is present on all 87/87 files, while `minecraft:atmosphere_identifier` (7/87), `minecraft:lighting_identifier` (7/87), `minecraft:color_grading_identifier` (1/87), and `minecraft:water_identifier` (2/87) are omitted from most overworld biomes — and `shader_compiler.dart` additionally writes invalid root keys `water_surface_color` and `water_surface_transparency`.
